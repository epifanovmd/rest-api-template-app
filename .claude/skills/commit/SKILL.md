# Коммит

Правила — [process/git](../../../docs/10-process/git.md).

1. `git status`, `git diff`: в коммит — только задача; без секретов, локальных
   настроек и артефактов ([process/git](../../../docs/10-process/git.md)).
2. Текущая ветка `main` — создать ветку задачи и сообщить.
3. Несколько логических изменений — предложить разбиение на коммиты.
4. Сообщение `<type>(<scope>)!: <описание>`: заголовок до 100 символов, на русском, со
   строчной буквы; детали — в теле.
5. `git add` нужных файлов, `git commit` (хуки не обходить). Хук отклонил — исправить
   причину, не `--no-verify`.
6. Push — только если пользователь попросил отдельно.

Подсказка: $ARGUMENTS
