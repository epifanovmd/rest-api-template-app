# Правка правил и документации

Пользователь явно поручил изменить правила или документацию
([protection](../../../docs/00-meta/protection.md)).

1. Менять только то, о чём просит пользователь. Попутное — предложением в inbox.
2. Место и формат — [authoring](../../../docs/00-meta/authoring.md): одно правило — в
   одном месте, остальные ссылаются; выжимки в `CLAUDE.md` и `.claude/rules`
   обновить вместе с источником.
3. Принятое предложение из `docs/inbox/` перенести и удалить файл предложения.
4. Новое архитектурное решение — ADR в `docs/20-architecture/adr/`.
5. Форматирование изменённых файлов и `yarn docs:index`.
6. Итог: что изменено (файлы).

Изменение: $ARGUMENTS
