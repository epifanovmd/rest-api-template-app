# Предложение правила

Протокол — [protection](../../../docs/00-meta/protection.md#предложение-правил).

1. Найти целевой документ по [authoring](../../../docs/00-meta/authoring.md#куда-класть);
   убедиться, что правила нет в другом месте.
2. Создать `docs/inbox/<YYYY-MM-DD>-<slug>.md` по
   [шаблону](../../../docs/00-meta/templates/inbox.md): ситуация, точный текст
   предложения, обоснование, `target`.
3. `yarn docs:index`.
4. В итоговом сообщении — список новых предложений. Защищённые документы не трогать.

Предложение: $ARGUMENTS
