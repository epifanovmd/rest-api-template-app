# Ревью

Чек-лист — [process/review](../../../docs/10-process/review.md).

1. Собрать diff: `git diff` и `git diff --staged` (или против `main`/указанной цели).
2. Изменения в нескольких слоях, общей инфраструктуре, публичных контрактах — отдать субагенту
   `reviewer` diff и описание задачи, без своих выводов. Иначе — самому.
3. Пройти чек-лист; каждое замечание — файл:строка и ссылка на правило.
4. Результат: блокирующие → желательные → вопросы. Пустой список — тоже результат.
5. Блокирующие свои замечания исправить до итога задачи.

Цель: $ARGUMENTS
