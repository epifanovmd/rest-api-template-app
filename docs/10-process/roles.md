# Роли

Роль — набор обязанностей и документов. Один агент может последовательно выполнять
несколько ролей; для независимого взгляда роль отдаётся субагенту.

| Роль       | Отвечает за                            | Этапы                  | Субагент     | Документы (`roles`)         |
| ---------- | -------------------------------------- | ---------------------- | ------------ | --------------------------- |
| architect  | место кода, границы, контракты, ADR    | анализ, план           | `architect`  | `20-architecture`, ADR      |
| developer  | реализация по плану и конвенциям       | выполнение             | —            | `30-conventions`, `50-tech` |
| tester     | воспроизведение багов, тесты, покрытие | выполнение, проверка   | `tester`     | `conventions/tests`         |
| reviewer   | сверка diff с правилами                | ревью                  | `reviewer`   | `process/review`            |
| devops     | окружение, сборка, деплой, хуки        | любые инфраструктурные | —            | `70-ops`                    |
| documenter | README модулей, предложения в inbox    | документация           | `documenter` | `00-meta`                   |

Индекс документов по ролям — [docs/README.md](../README.md#по-ролям).

## Правила делегирования

- Субагент получает задачу, файлы и документы для чтения, границы scope — и не
  получает готовый вывод, который должен проверить.
- Результат субагента проверяется: его ошибки выглядят так же уверенно, как находки.
- Параллельно — только независимые части; одну и ту же работу не делать дважды.
