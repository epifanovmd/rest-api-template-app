# Проверки и Definition of Done

Конкретные команды проекта — [ops/commands](../70-ops/commands.md).

## После итерации

- Линтер по проекту — 0 ошибок и 0 новых предупреждений (включая архитектурные границы).
- Проверка типов — 0 ошибок.
- Тесты затронутой области.

## Перед сдачей

- Полная проверка проекта из [ops/commands](../70-ops/commands.md): линтер, типы,
  тесты; формат и пороги покрытия — если они в ней есть;
  сборка — если её требует
  [ops/commands](../70-ops/commands.md).
- `git diff --check` — без пробельных ошибок.
- Результат каждой проверки — в отчёт с фактическим выводом (число тестов, ошибок).
  Не писать «проверено», если проверка не запускалась.

## Definition of Done

- [ ] Поведение соответствует задаче; для бага — регрессионный тест зелёный.
- [ ] Код размещён по [architecture/placement](../20-architecture/placement.md),
      границы слоёв не нарушены.
- [ ] Соблюдены [конвенции](../30-conventions/naming.md) — линтер чистый.
- [ ] Новое поведение покрыто тестами соразмерно риску.
- [ ] Полная проверка зелёная.
- [ ] README модулей обновлены; предложения в inbox оформлены.
- [ ] Отчёт: сделано, проверено, не проверено, замечено вне scope.

## Если проверка падает

- Падение, вызванное задачей, исправляется в рамках задачи.
- Падение, существовавшее до задачи, — проверить на чистом `main` и сообщить
  пользователю; не чинить молча и не отключать проверку.
