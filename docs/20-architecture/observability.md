# Наблюдаемость

- **Логи** — структурированный логгер, единый на приложение; `console.*` не
  используется. Чувствительные поля редактируются на уровне логгера. Идентификатор
  запроса (или задачи) попадает в каждую запись через асинхронный контекст, без
  передачи логгера по цепочке. 5xx логируются с контекстом, 4xx — нет.
- **Метрики** — в формате Prometheus на системном маршруте, с необязательной защитой
  токеном: HTTP (метка маршрута — шаблон, не URL), ошибки по машинному коду, задачи
  по очередям, соединения реального времени, метрики процесса. Воркер отдаёт свои
  метрики тем же маршрутом.
- **Ошибки** — 5xx и фатальные ошибки процесса уходят в трекер ошибок, если он
  настроен.
- **Здоровье:** liveness — процесс жив; readiness — бутстраперы завершены и БД
  доступна; health — живые проверки БД, Redis и индикаторов модулей с таймаутом.
  Модуль добавляет проверку своей зависимости индикатором здоровья
  ([extension-points](extension-points.md)).
