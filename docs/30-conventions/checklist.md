# Чек-лист стека для ревью

Дополняет общий чек-лист [process/review](../10-process/review.md).

**Архитектура** — [placement](../20-architecture/placement.md),
[dependencies](../20-architecture/dependencies.md),
[module-layers](../20-architecture/module-layers.md)

- [ ] Ядро не знает о модулях; нет циклов между модулями.
- [ ] Каждый класс на своём слое; реакции между модулями — через события, а не
      прямой вызов сервиса другого модуля.
- [ ] Новый модуль зарегистрирован в корневом модуле, провайдеры — в его `@Module`.
- [ ] Контракт принадлежит потребителю; все реализации реестра соблюдают контракт.

**HTTP** — [controllers](controllers.md), [dto-validation](dto-validation.md)

- [ ] Контроллер тонкий; маршрут под версией; `@Response` по умолчанию; `UUID` в
      path; 201/204; security-scope — право, а не роль.
- [ ] Наружу уходит DTO, а не сущность; списки — `IPaginatedDto`/`ICursorPageDto`,
      лимит нормализован.
- [ ] Валидация входа — схемой на маршруте или событии; длины совпадают с БД.
- [ ] Маршруты и спецификация перегенерированы.

**Доступ** — [access](../20-architecture/access.md)

- [ ] Новое право объявлено в реестре прав и использовано в security-scope.
- [ ] Сущность с владельцем: право объявлено с областью, маршрут требует `:own`,
      сервис проверяет через `OwnedAccess` (404 / 403), список — с `mine`, события —
      своим лично.
- [ ] Смена смысла прав — миграцией данных без потери доступа.

**Сервисы и данные** — [services-repositories](services-repositories.md),
[entities-migrations](entities-migrations.md)

- [ ] Сервис бросает доменные ошибки модуля; конфликт состояния — 409.
- [ ] Ошибка обрабатывается на одном уровне; нет `throw new Error` и `!` для `null`.
- [ ] Несколько записей — в транзакции; события — после фиксации.
- [ ] Репозиторий без бизнес-логики.
- [ ] Nullable — `| null`; enum-ы — в `*.types.ts`.
- [ ] Миграция сгенерирована и просмотрена; применённые миграции не изменены.

**Фон, события, файлы** — [jobs](jobs.md), [events](events.md), [files](files.md)

- [ ] Фоновая и периодическая работа — задачами очереди (`cron`); постановка в
      транзакции; обработчик идемпотентен.
- [ ] Реальное время — через слушатель и эмиттер, не из сервиса; входящие события —
      через `onValidated`.
- [ ] Файлы — по ключам хранилища, наружу только подписанные ссылки, подписанные
      пачкой.

**Конфигурация и логи** — [config](config.md), [errors-logging](errors-logging.md)

- [ ] Новая конфигурация — в схеме и шаблоне окружения; `process.env` не читается
      вне конфигурации.
- [ ] Логи структурированы; секреты не утекают.

**Тесты** — [tests](tests.md)

- [ ] Юнит-тесты сервиса и схем; новый эндпоинт покрыт e2e-сценарием.
- [ ] Изменение API, схемы или инфраструктуры — e2e зелёный.
