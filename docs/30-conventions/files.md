# Работа с файлами

Модель хранилища — [architecture/files](../20-architecture/files.md).

- Работа с файлами — только через абстракцию хранилища по ключу; пути ФС и адреса
  хранилища в коде модулей не используются.
- Все объекты одной сущности — под общим префиксом ключа, удаляются вместе.
- Ссылки для клиента подписываются пачкой до сборки DTO; DTO берёт их из карты.
- Проверка загрузки: белый список расширений, согласованный MIME, сигнатура
  содержимого, лимит размера.
- Обработка медиа — задачей на воркере.
