# Функции и асинхронность

## Стрелочные функции

- Все функции — стрелочные: `const fn = (a: A): B => {}`,
  `export const fn = async <T>(x: T) => {}`. Объявления `function` и выражения
  `function` не используются, включая хелперы модуля, type guards, фабрики и
  callback-и. Проверяется линтером.
- Методы классов остаются методами. Декораторы применяются к классам и методам.
- У `const` нет hoisting: хелпер объявляется выше первого использования.
- Исключение — файлы деклараций типов и код, которым владеет фреймворк.

## Контракт функции

Функция:

- выполняет одну связную операцию на одном уровне абстракции;
- получает зависимости явно и возвращает предсказуемый тип;
- не меняет входные данные без контракта;
- не скрывает I/O под именем вычисления.

Чистая функция предпочтительна, когда задача — вычисление (проверка права, разбор
токена, расчёт пагинации).

Несколько boolean-параметров скрывают смысл — вместо них объект опций:

```ts
// Плохо
sendNotification(userId, true, false);

// Лучше
sendNotification(userId, { silent: true, retry: false });
```

Если опции выбирают разные алгоритмы — отдельные методы или Strategy.

Хелпер или приватный метод выносится, когда логика повторяется, имеет отдельное
предметное имя или мешает читать основной сценарий сверху вниз; не ради уменьшения
файла.

## Асинхронность

- `await` каждого промиса, результат которого важен; fire-and-forget — только через
  EventBus или с явным `.catch` и логом.
- Параллельные независимые операции — `Promise.all`/`allSettled`, а не
  последовательный `await` в цикле.
- Транзакции — короткие ([data](../20-architecture/data.md#транзакции-и-согласованность)).
