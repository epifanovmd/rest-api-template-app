# Продукт и стек

Шаблон серверного приложения: модульный монолит на Node.js + TypeScript с
версионированным REST API (`/api/v1/...`), OpenAPI из декораторов, real-time по
Socket.IO, очередью фоновых задач и хранилищем файлов по подписанным ссылкам.

Для кого: старт нового бэкенда — проект начинается с копии шаблона и добавляет
предметные модули поверх платформы. Клиенты — веб- и мобильные приложения
(OpenAPI-спецификация для генерации клиента, сокеты для живых обновлений).

## Что входит в платформу

| Область             | Что есть                                                                         |
| ------------------- | -------------------------------------------------------------------------------- |
| аккаунт             | регистрация, вход, 2FA, сброс пароля, подтверждение и смена email                |
| альтернативный вход | биометрия (подпись nonce), passkeys (WebAuthn)                                   |
| сессии              | session-bound JWT, ротация refresh, отзыв, список и завершение сессий            |
| доступ              | роли и права, области «все / свои», API-ключи для сервисов ([access](access.md)) |
| профиль             | данные профиля, аватар, приватность, присутствие online/offline                  |
| файлы               | загрузка (multipart и прямая по ссылке), обработка медиа в фоне, сборка мусора   |
| аудит               | журнал событий безопасности: свой и общий                                        |
| инфраструктура      | задачи и cron (pg-boss), почта по шаблонам, сокеты, метрики, health-пробы        |

Предметных модулей в шаблоне нет — блок модулей проекта в `src/app.module.ts` пуст.
Модули и их назначение — [modules](modules.md), термины — [glossary](glossary.md),
события в реальном времени — [realtime](realtime.md).

## Роли процесса (`APP_ROLE`)

Один образ запускается в одной из ролей:

| Роль     | HTTP                   | Клиентские сокеты                           | Задачи                              |
| -------- | ---------------------- | ------------------------------------------- | ----------------------------------- |
| `api`    | весь API               | да                                          | только ставит в очередь             |
| `worker` | только пробы и метрики | нет; события клиентам — через Redis-адаптер | выполняет задачи и cron             |
| `all`    | весь API               | да                                          | всё — для разработки (по умолчанию) |

API масштабируется репликами, воркеры — отдельными процессами; общее состояние — в
Postgres и Redis ([tech/redis-state](../50-tech/redis-state.md)).

## Стек

| Компонент     | Технология                                                                    |
| ------------- | ----------------------------------------------------------------------------- |
| Runtime       | Node.js ≥ 22.13 (Docker — 24), TypeScript ~6, сборка `tsc`                    |
| HTTP          | Koa 3 + tsoa 6.6.0 (закреплён), `@koa/router`, `@koa/multer`, koa2-swagger-ui |
| DI            | Inversify 8                                                                   |
| БД            | PostgreSQL + TypeORM 1.x                                                      |
| Задачи        | pg-boss 12 (схема `pgboss` в той же БД)                                       |
| Межпроцессное | Redis (ioredis), `@socket.io/redis-adapter`                                   |
| Real-time     | Socket.IO 4 (только websocket)                                                |
| Хранилище     | S3 (`@aws-sdk/client-s3` + presigner; локально SeaweedFS) или локальный диск  |
| Auth          | jsonwebtoken (HS256), scrypt, `@simplewebauthn/server`                        |
| Почта         | nodemailer + EJS, шаблоны `templates/mail/<locale>/`                          |
| Медиа         | sharp, blurhash, ffmpeg (только образ `worker`), file-type                    |
| Валидация     | Zod 4 (вход и конфигурация)                                                   |
| Наблюдаемость | pino, prom-client, Sentry                                                     |
| Безопасность  | koa-helmet, CORS, koa-ratelimit                                               |
| Тесты         | Mocha + Chai + Sinon; e2e — `test/e2e` против настоящего сервера              |
| Инструменты   | ESLint 10 (flat) + typescript-eslint, Prettier 3, lefthook                    |
