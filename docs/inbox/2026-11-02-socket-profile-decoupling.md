# Инфраструктурный модуль не импортирует доменные

## Ситуация

`modules/socket/socket.bootstrap.ts` импортирует `UserOnlineEvent` и
`UserOfflineEvent` из `../profile/events` — инфраструктурный модуль знает доменный.
Импорт через `index.ts` профиля даёт цикл загрузки socket ↔ profile (профиль
импортирует `onValidated`, `ISocketHandler` из socket), поэтому в страже
`src/modules/module-boundaries.test.ts` это известное исключение.

## Предложение

В `dependencies.md`, раздел «Связи между модулями», добавить пункт:

> Инфраструктурный модуль (транспорт, очередь, хранилище) не импортирует доменные
> модули: связь — событиями, объявленными в самом инфраструктурном модуле, или
> токеном-реестром, который реализует доменный модуль.

Отдельной задачей привести код к правилу и убрать исключение из стража.

## Обоснование

Цикл через barrel запрещён, исключение в страже — техдолг. Новые инфраструктурные
модули повторят ту же связь, если правило не записано. Варианты развязки: события
присутствия объявить в socket, профиль на них подписывается; либо socket сообщает о
подключении через токен-реестр, который реализует профиль.
