# Inbox — предложения правил

Сюда агент записывает предложения: новое правило для повторяющейся ситуации,
противоречие, устаревший факт в защищённом документе. Порядок —
[meta/protection](../00-meta/protection.md#предложение-правил), шаблон —
[templates/inbox.md](../00-meta/templates/inbox.md).

- Один файл — одно предложение: `<YYYY-MM-DD>-<slug>.md`.
- Принятое переносится в целевой документ через `/docs-edit`, файл удаляется.
- Отклонённое удаляется.

Открытые предложения — все файлы этой папки, кроме README.
